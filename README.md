# D’AMORE — демо-версія сайту (портфоліо)

Статична копія сайту бренду догляду за волоссям D’AMORE (Trend Studio). Оригінал зроблений на Tilda; тут усі сторінки зібрані з тих самих блоків у звичайні HTML-файли, тож сайт працює без Tilda й без Cloudinary.

**Що всередині**
- `index.html` — головна (прелоадер, відео-hero, слайдер, до/після, розділи, блог, «про бренд», переваги, футер)
- `about/` — сторінка «Про бренд»
- `catalog/` — каталог і сторінка товару `catalog/cold-reconstruction/` (hero, картка, вкладки: етапи, склад, для кого, питання)
- `catalog/home-care`, `body-care`, `accessories`, `gifts` — розділи «скоро»
- `blog/` — блог (статичні картки)
- `assets/` — фото, відео та `demo.js`

**Що вимкнено в демо-версії**
- Кошик і оплата: кнопки «Додати до кошика» лише показують підказку й рахують товари в браузері (`assets/demo.js`).
- Сторінки статей блогу, оферта, політика конфіденційності, доставка: посилання показують підказку «не входить у демо-версію».
- Шрифти (Onest, Pinyon Script) підключаються з Google Fonts; для повного офлайну їх можна завантажити в `assets/fonts/`.

## Як опублікувати на GitHub Pages
1. На github.com створіть новий репозиторій (наприклад `damore-site`), публічний.
2. Завантажте весь вміст цієї папки в репозиторій (кнопка **Add file → Upload files** або `git push`). Файли `.nojekyll` і `404.html` мають лежати в корені.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.**
4. Через 1–2 хвилини сайт буде за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

Усі посилання на сайті відносні, тому він працює і в піддиректорії GitHub Pages, і на власному домені, і при відкритті файлів локально (`index.html` двічі клацнути; відео й анімації краще дивитись через локальний сервер).

## Як змінювати
Тексти й налаштування кожного блоку лежать у блоці `CONFIG` у відповідному `index.html` (шукайте `CONFIG`). Папка `_build/` містить скрипт збірки `build.ps1`, який збирає сторінки з вихідних блоків (потрібна папка `Site_Shampoo` поруч); для звичайного використання сайту вона не потрібна.
